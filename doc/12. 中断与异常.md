# 中断函数

## 简介

- 内中断
    - 软中断：
        - 系统调用：读写文件
    - 异常：
        - 除零
        - 指令错误
        - 缺页错误
- 外中断：
    - 时钟中断
    - 键盘中断
    - 硬盘中断：
        - 同步端口IO
        - 异步端口IO
        - DMA Direct Memory Access

## 中断触发点

- 取指：将 eip 指向的指令读入处理器
- 译码：将指令的微程序写入流水线 (多级 cache)
- 执行：执行指令
- 中断：处理中断

## 中断函数指令区别

* call / ret
    * eip
* int(interrupt) / iret (interrupt return)
    - eip
    - cs 恢复代码段寄存器 TODO: 用于内核态和用户态的切换
    - eflags 状态与控制标志寄存器 进入中断后外中断运行标志位IF会被置0，禁止所有的外中断，iret后恢复中断


关于elfags的一些操作: Interrupt Flag 外中断允许标志，CPU 外中断的总开关

```s
int; 将eflag保存
iret; 恢复eflag

sti; 设置 IF 位 (set interrupt)，允许外中断
cli; 清除 IF 位 (clear interrupt)，禁止外中断

pushf; 将 elags 压入栈中
popf; 将栈顶弹出到 eflags
```

## 中断向量表 实模式

中断向量就是中断函数的指针

实模式：`0x000` ~ `0x3ff` 存放中断函数指针，使用int nr 调用中断函数


## 中断描述符 保护模式

在保护模式下，处理器对中断的管理是相似的，但并非使用传统的中断向量表来保存中断处理函数的地址；

中断向量 --> 中断描述符
中断向量表 --> 中断描述符表 

Interrupt Descriptor Table (IDT)

- 代码段 (cs)
- 段内偏移地址 (eip)
- 一些属性


```c++
typedef struct gate_t
{
    u16 offset0;    // 段内偏移 0 ~ 15 位 用于保存中断函数地址
    u16 selector;   // 代码段选择子 中断函数地址所对应的段选择子
    u8 reserved;    // 保留不用
    u8 type : 4;    // 任务门/中断门/陷阱门
    u8 segment : 1; // segment = 0 表示系统段
    u8 DPL : 2;     // 使用 int 指令访问的最低权限
    u8 present : 1; // 是否有效
    u16 offset1;    // 段内偏移 16 ~ 31 位
} _packed gate_t;
```

1. 设置segment为系统段

2. 设置type为中断门

- ~~0b0101 - 任务门 (Task Gate)：很复杂，而且很低效 x64 就去掉了这种门~~
- 0b1110 - **中断门** (Interrupt Gate) `IF` 位自动置为 0
- 0b1111 - 陷阱门 (Trap Gate)

## 中断描述符表 Interrupt Descriptor Table (IDT)

和全局描述符表类似

```c++
gate_t idt[IDT_SIZE];
```

- idtr / 中断描述符表的起始位置和长度

```s
lidt [idt_ptr]; 加载 idt
sidt [idt_ptr]; 保存 idt
```

```cpp
typedef struct pointer
{
    unsigned short limit; // size - 1
    unsigned int base;
} __attribute__((packed)) pointer;
```

- 故障 Fault: 这种错误是可以被修复的一种类型，属于最轻的一种异常；

- 终止 Abort: 是最严重的异常类型，一旦出现由于 错误无法修复，程序将无法继续运行；
