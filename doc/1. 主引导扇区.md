# 主引导扇区

## BIOS

Basic Input Output System

用到的两个BIOS功能:
- BIOS 在加电自检将主引导扇区读 0x7c00 位置，并跳转到这里执行。**BIOS有基本的磁盘读写驱动，所以可以加载磁盘内容到内存**
- int 0x10; BIOS 系统调用，显示器相关的功能

## 实模式

8086模式，16位，保护模式

- Real Mode
- Protected Mode

```s
; 0xb8000 文本显示器的内存区域
mov ax, 0xb800
mov ds, ax ; 段寄存器不能直接用立即数设置。
mov byte [0], 'H'
```
## 实模式的寻址方式

使用DS寄存器作为段寄存器，之后操作的地址: phy_addr = DS << 4 + virt_addr


## 主引导扇区的结构

主引导扇区只有512字节，其结构如下:

sect             | size |function
-----------------|------|----------
0x0000 ~ 0x01BD  | 446  | 引导代码（Bootstrap Code）
0x01BE ~ 0x01FD  | 64   | 分区表（4个分区×16字节）早期的分区表使用的CHS，现代系统使用LBA
0x01FE ~ 0x01FF  | 2    | 引导签名（0x55AA）

MBR的局限性：
- 只支持4个主分区（或通过扩展分区支持更多逻辑分区）。
- 最大支持2TB的磁盘容量（由于32位LBA寻址限制）。这就是传统BIOS(BIOS legacy 只支持2T磁盘的原因)
- 不支持现代大容量磁盘和复杂分区方案。
- 替代方案：现代系统逐渐转向GPT（GUID Partition Table），它支持更大磁盘容量、更多分区，并与UEFI配合使用，取代了MBR的角色。

三种模式：
- BIOS + MBR
- BIOS + GPT
- UEFI + GPT

查看分区表: `fdisk -l` 可以看到一般都是GPT分区
