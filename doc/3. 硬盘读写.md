# 硬盘读写

## 硬盘原理

- CHS 柱面、磁头、扇区磁盘寻址模式
- LBA 逻辑块地址寻址模式

## in out 指令

- x86 架构使用 独立的 I/O 地址空间，与内存地址空间分开。I/O 端口地址范围为 0x0000 到 0xFFFF（共 64KB）。
- 端口地址可以由立即数直接指定（8 位地址，0x00–0xFF），或通过 DX 寄存器间接指定（16 位地址，0x0000–0xFFFF）。
- 每个端口通常对应外设的某个寄存器（如 UART、键盘控制器、PIC 等）。

为什么 x86 不像 ARM 一样直接操作物理地址？

- x86 的起源：x86 架构始于 1978 年的 8086 处理器，设计时受限于当时的硬件技术和成本。独立 I/O 地址空间是 Intel 借鉴了早期微处理器（如 8080）的设计，简化了与外设的交互。
- ARM 的背景：ARM 架构诞生于 1980 年代，针对嵌入式系统优化，采用更现代的内存映射 I/O，减少了硬件复杂性，适合统一的地址空间管理。

## IDE / ATA PIO Mode

Port Input Output 端口输出输出模式

端口是外部设备内部的寄存器；

- IDE：Integrated Drive Electronics 集成电子驱动器 / 西部数据
- ATA：Advanced Technology Attachment  / American National Standards Institute ANSI 美国国家保准学会
- SATA / PATA

### 使用PIO方式硬盘读写

LBA28模式，总共能访问 128G 的磁盘空间（LBA28 表示使用28位逻辑块地址，能够寻址的扇区范围为2^28个扇区。）

支持两种读写法：(0x1F6选择读写方法)
- CHS 模式 / Cylinder / Head / Sector
- LBA 模式 / Logical Block Address

硬盘控制端口，使用in/out操作Primary通道：
| Primary 通道            | Secondary 通道  | in 操作      | out 操作     |
| ----------------------- | -------------- | ------------ | ------------ |
| 0x1F0                   | 0x170          | Data         | Data         |
| 0x1F1                   | 0x171          | Error        | Features     |
| 0x1F2                   | 0x172          | Sector count | Sector count |
| 0x1F3                   | 0x173          | LBA low      | LBA low      |
| 0x1F4                   | 0x174          | LBA mid      | LBA mid      |
| 0x1F5                   | 0x175          | LBA high     | LBA high     |
| 0x1F6                   | 0x176          | Device       | Device       |
| 0x1F7                   | 0x177          | Status       | Command      |

IDE控制器的标准I/O端口:
- 0x1F0：16bit 端口，用于读写数据: 读取时，in 指令从此端口获取扇区数据；写入时，out 指令将数据发送到硬盘。
- 0x1F1：检测前一个指令的错误
- 0x1F2：读写扇区的数量
- 0x1F3：起始扇区的 0 ~ 7 位
- 0x1F4：起始扇区的 8 ~ 15 位
- 0x1F5：起始扇区的 16 ~ 23 位
- 0x1F6:
    - 0 ~ 3：起始扇区的 24 ~ 27 位
    - 4: 0 主盘, 1 从片
    - 6: 0 CHS, 1 LBA
    - 5 ~ 7：固定为1
- 0x1F7: out
    - 0xEC: 识别硬盘
    - 0x20: 读硬盘
    - 0x30: 写硬盘
- 0x1F7: in / 8bit
    - 0 ERR
    - 3 DRQ 数据准备完毕
    - 7 BSY 硬盘繁忙
