# printk

## 可变参数原理

```c++
int printf(const char* format, ...);
```

- `va_list`：保存可变参数指针
- `va_start`：启用可变参数
- `va_arg`：获取下一个参数
- `va_end`：结束可变参数

```s
; 高地址
; +-----------------+
; | arg n           |
; | arg n-1         |
; | ...             |
; | arg 1           | ← EBP + 8（第一个参数） 1. 调用前设置函数参数
; | 返回地址         | ← EBP + 4             2. call命令压入eip
; | 保存的 EBP       | ← EBP（基址指针）       3. 保存调用的ebp
; | local variable  | ← EBP - 4             4. 局部变量
; | local variable  | ← EBP - 8
; | ...             |
; | local variable  | ← ESP（栈指针）
; +-----------------+
; 低地址
```

```c
#define va_list char *
#define va_start(ap, v) (ap = (va_list)&v + sizeof(char *)) // 第一个参数 + 4 = 第二个参数
#define va_arg(ap, t) (*(t *)((ap += sizeof(char *)) - sizeof(char *))) // 先 + 4 到第三个参数，然后 - 4 回到第二个参数
#define va_end(ap) (ap = (va_list)0)

void my_print(char *x, ...) {

    // 通过 char *x 中的各种格式化字符串判断下一个参数的类型

    va_list ap;
    va_start(ap, x); // ap 指向 x 后的第一个参数
    printf("First arg: %d\n", x);

    int next = va_arg(ap, int); // 提取第一个可变参数
    printf("Next arg: %d\n", next);

    char *str = va_arg(ap, char *); // 提取第二个可变参数
    printf("Next arg: %s\n", str);

    va_end(ap); // 清理 ap
}
```
