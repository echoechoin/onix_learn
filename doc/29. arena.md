# arena

内存管理的一种方式

## 原理

将分配内存大小区分为：0~15 16~31 32~63 64~127 128~255 256~511 512~1023 1024~inf

```c
```c++
typedef struct arena_descriptor_t
{
    u32 total_block;  // 总的块数量
    u32 block_size;   // 块大小
    list_t free_list; // 空闲的快数量
} arena_descriptor_t;

#define DESC_COUNT 7 // 对应7个内存大小区间：0~15 16~31 32~63 64~127 128~255 256~511 512~1023
static arena_descriptor_t descriptors[DESC_COUNT];

typedef struct arena_t
{
    arena_descriptor_t *desc; // 表示该 arena 被哪个descriptor管理
    u32 count;                // 块大小/页数量
    u32 large;                // 是否大于1024
    u32 magic;                // 用于检测内存溢出
} arena_t;
```

- 如果需要分配的内存超过 1024 字节，直接分配n页内存为arena

- 如果需要分配的内存小于 1024 字节，找到对应的 descriptor，查看该 descriptor 里有没有空闲的块
    - 如果有，则分配出去；
    - 如果没有，分配一页内存，然后再分配为n块存储到空闲列表中，然后在空闲列表中取出一块；
