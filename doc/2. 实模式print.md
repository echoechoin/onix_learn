# 实模式 print

## 工作原理
BIOS中断实现在实模式输出字符
- ah: 0x0e 对于打印字符，通常使用功能号0x0E（Teletype输出模式）。
- al: 字符（ascii码）
- int 0x10 BIOS中断输出字符；BIOS自动更新光标位置


## 代码实现
```s
mov si, booting
call print

; 阻塞
jmp $

print:
    mov ah, 0x0e
.next:
    mov al, [si]
    cmp al, 0
    jz .done
    int 0x10
    inc si
    jmp .next
.done:
    ret

booting:
    db "Booting Onix...", 10, 13, 0; \n\r
```
