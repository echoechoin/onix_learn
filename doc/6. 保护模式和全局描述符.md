## 全局描述符

- 内存的起始位置
- 内存的长度、界限 = 长度 - 1
- 内存属性

```cpp
typedef struct descriptor /* 共 8 个字节 */
{
    unsigned short limit_low;      // 段界限 0 ~ 15 位: 也就是内存界限，只有19位 因此每位表示4KB, 要设置4G 的内存界限，全设置为1即可，但是需要 - 1,因为界限 = 长度 - 1
    unsigned int base_low : 24;    // 基地址 0 ~ 23 位: 内存开始的位置；设置为0，之后实模式和BISO里的内容将不再存在
    unsigned char type : 4;        // 段类型: 
    unsigned char segment : 1;     // 1 表示代码段或数据段，0 表示系统段: 设置为0 表示我们要设置代码段
    unsigned char DPL : 2;         // Descriptor Privilege Level 描述符特权等级 0 ~ 3: 设置为0 表示最高特权
    unsigned char present : 1;     // 存在位，1 在内存中，0 在磁盘上; 我们暂时设置为1即可
    unsigned char limit_high : 4;  // 段界限 16 ~ 19;
    unsigned char available : 1;   // 该安排的都安排了，送给操作系统吧，对于CPU来说没用
    unsigned char long_mode : 1;   // 64 位扩展标志 设置为 0 即可
    unsigned char big : 1;         // 32 位 还是 16 位; 设置为1表示 wield 32位
    unsigned char granularity : 1; // 粒度 4KB 或 1B 设置为1 表示为4K
    unsigned char base_high;       // 基地址 24 ~ 31 位
} __attribute__((packed)) descriptor;
```

### 1. segment = 1 时 type的作用

segment = 0 时的 type 暂不考虑

| X | C/E | R/W | A |

- A: Accessed 是否被 CPU 访问过；由cpu设置，用于调试
- X: 1为代码段 0为数据
- X = 1：为代码段时 X C R A
    - C: 是否是一致代码段；一致代码段允许较低特权级的程序（如 CPL=3 的用户态）调用高特权级的代码段（如 DPL=0 的内核代码），但不改变调用者的特权级; 设置为不依从即可
    - R: 是否可读; 设置为可读即可
- X = 0: 为数据段时 X E W A
    - E: 0 向上扩展 / 1 向下扩展; 设置为向上扩展
    - W: 是否可写; 设置为可写


### 2. 全局描述符表 GDT Global Descriptor Table

存储在一段内存上，CPU最多可以读取4096个描述符，但是第一个描述符只能设置为NULL

```cpp
typedef struct pointer
{
    unsigned short limit; // size - 1
    unsigned int base;
} __attribute__((packed)) pointer;
```

使用如下指令可以加载和保存CPU上生效的全局描述符表

```s
lgdt [gdt_ptr]; 加载 gdt
sgdt [gdt_ptr]; 保存 gdt
```





### 段选择子

- 只需要一个代码段
- 需要一个或多个数据段 / 栈段 / 数据段
- 加载到段寄存器中 / 校验特权级

```cpp
typedef struct selector
{
    unsigned char RPL : 2; // Request PL 
    unsigned char TI : 1; // 0  全局描述符 1 局部描述符 LDT Local 
    unsigned short index : 13; // 全局描述符表索引
} __attribute__((packed)) selector;
```

## 跳转方法

1. 使用cli禁止中断以防中断处理程序破坏状态

2. 打开 A20 线，这样可以读取 1M 以上的内存

```s
in al,  0x92
or al, 0b10
out 0x92, al
```

2. 加载全局描述符 `lgdt [gdt_ptr]`

由于保护模式的寻址方式为 选择子:偏移 因此至少需要指定`代码段选择子`和`数据段选择子`

3. 启动保护模式: 将控制寄存器 CR0 的最低位（PE 位，位 0）置 1。

```s
mov eax, cr0
or eax, 1
mov cr0, eax
```

4. 刷新流水线并跳转

```s
; CODE_SELECTOR 代码段在 GDT 中的选择子
; protected_mode_entry 保护模式下的入口点线性地址
jmp CODE_SELECTOR:protected_mode_entry
```

5. 更新段寄存器

保护模式下段寄存器变成了段选择子：

```s
mov ax, DATA_SELECTOR
mov ds, ax
mov es, ax
mov fs, ax
mov gs, ax
mov ss, ax
```
