# 编译链接

详见 Makefile 注释

## 编译

将main.c 编译为 elf 格式的文件

```Makefile
CFLAGS:= -m32 # 32 位的程序
CFLAGS+= -fno-builtin	# 不需要 gcc 内置函数
CFLAGS+= -nostdinc		# 不需要标准头文件
CFLAGS+= -fno-pic		# 不需要位置无关的代码  position independent code
CFLAGS+= -fno-pie		# 不需要位置无关的可执行程序 position independent executable
CFLAGS+= -nostdlib		# 不需要标准库
CFLAGS+= -fno-stack-protector	# 不需要栈保护

$(CC) $(CFLAGS) $(DEBUG) $(INCLUDE) -c $< -o $@
```

将汇编语言编译为 elf 格式的文件

```Makefile
$(NASM) -f elf32 $(DEBUG) $< -o $@
```

## 链接

```ld
// 一个典型的链接器脚本包含以下核心部分：
// 
// 入口点（ENTRY）：指定程序的入口地址（默认是 _start）。
// 内存区域（MEMORY）：定义目标硬件的内存区域（如 RAM、ROM）。
// 段定义（SECTIONS）：描述输入段如何映射到输出段，并指定它们的地址、属性和内容。
// 符号定义：为程序提供符号（如变量或函数的地址）。
// 其他控制：如对齐、填充或丢弃某些段。

// 这里我们只需要定义段
SECTIONS {
    // 设置链接器的位置计数器（location counter）
    // 从这个地址开始，链接器将后续的段（如 .text、.data）依次放置在内存中。
    . = 0x10000;

    // .text：定义输出文件的代码段（.text），通常包含程序的机器指令。
    // *(.text)：
    //   * 表示所有输入文件（如 start.o 和 main.o）。
    //   (.text) 表示每个输入文件的 .text 段。
    //   合起来，*(.text) 告诉链接器将所有输入文件的 .text 段合并到输出文件的 .text 段中，并放置在当前位置计数器（0x10000）开始的地址。
    .text : { *(.text) }

    // .data 段的地址从 .text 段结束处开始，链接器会自动推进位置计数器。
    .data : { *(.data) }

    // .bss 段的地址从 .data 段结束处开始，链接器会自动推进位置计数器。
    .bss : { *(.bss) }
}
```

```Makefile
$(LD) -m elf_i386 -static $^ -o $@ -T linker.ld
```

## 转换为纯二进制

```Makefile
$(OBJCOPY) -O binary $< $@
```

## 组装

```Makefile
$(DD) if=/dev/zero of=$@ bs=512 count=256
$(DD) if=$(TARGET)/bootloader/boot.bin   of=$@ bs=512 count=1 seek=0 conv=notrunc
$(DD) if=$(TARGET)/bootloader/loader.bin of=$@ bs=512 count=1 seek=2 conv=notrunc
$(DD) if=$(TARGET)/system.bin of=$@ bs=512 count=1 seek=3 conv=notrunc
```
