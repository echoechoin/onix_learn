# 进入内核

## 整理项目目录

- boot
- kernel

## 编写简单内核

```s
[bits 32]

global _start
_start:
    mov byte [0xb8000], 'K'; 表示进入了内核
    jmp $; 阻塞
```

## 此时扇区格式如下：
  0 | boot.bin
  1 | 0
  2 | loader.bin
  3 | kernel.bin
  4 | 0
  ...
  255 | 0

## 此时内存结构如下


| start addr| end addr  | size     | 
| --------- | --------- | -------- | ------------------
| `0x07c00` | `0x7dff`  | 512B     | boot.bin (到了kernel.bin后不再有效)
| ...       | ...       | ...      |
| `0x1000`  | `0x11ff`  | 512B     | loader.bin (到了kernel.bin后不再有效)
| ...       | ...       | ...      |
| `0x10000` | `0x111ff` | 512B     | kernel.bin 执行_start
